# Roadmap

Ideas that are not built yet, roughly in order. Open an issue before starting a big one.

- [ ] Resize a note (drag the bottom-right corner) and remember the size.
- [ ] Undo for done and delete (a toast with "Undo" for a few seconds).
- [ ] Recurring due times (every day, every week) for routine notes.
- [ ] Group notes into named zones on the glass ("Today", "This week").
- [ ] Live updates between tabs and devices (Server-Sent Events from the handler).
- [ ] Paste or drop an image onto the glass to create a note with it.
- [ ] Publish to npm once the API has settled on real use.
- [ ] Optional light-glass theme that follows `prefers-color-scheme`.
